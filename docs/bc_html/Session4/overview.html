Instruccions de muntatge¶

En aquesta sessió:

  • Col·laborareu per muntar un ordinador de manera segura.

  • Elaborareu un tutorial de muntatge detallant cada pas i documentant el procés de manera sequëncial amb fotos i descripcions.

  • Col·laborareu en els vostres grups per muntar un ordinador de manera segura.

  • Elaborareu un tutorial de muntatge detallant cada pas i documentant el procés de manera sequëncial amb fotos i descripcions.

El muntatge d’ordinadors és una tasca essencial per a un tècnic d’instal·lació informàtica. És un procés en què s’instal·len tots els components interns necessàris perquè el sistema informàtic sigui funcional. Hi ha una sequëncia adequada de fixació per a cada component en el sistema d’ordinador.

És un procés sistemàtic. Comenceu organitzant les peçes de l’ordinador.

Materials necessàris:

  • Carcassa d’ordinador amb la PSU instal·lada

  • Placa base

  • CPU

  • Dissipador de calor/ventilador

  • Pasta tèrmica

  • Mòdul(s) de RAM

  • Separadors i cargols de la placa base

  • Polsera i estora antielect rostàtiques

  • Joc d’eines
